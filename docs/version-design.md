# Balanced Version：二维软件迭代约定

本页面以上游 [dual_balanced_ternary.rs](https://github.com/dual-balanced-ternary/dual_balanced_ternary.rs) 的 [src/digit.rs](https://github.com/dual-balanced-ternary/dual_balanced_ternary.rs/blob/main/src/digit.rs) 和 [MATHEMATICS.md](https://github.com/dual-balanced-ternary/dual_balanced_ternary.rs/blob/main/MATHEMATICS.md) 为数学依据。DBT 每位是两个平衡三进制位，使用洛书编号：

```text
6 1 8
7 5 3
2 9 4
```

沿用原坐标 `(x, y)`：水平 x 是修复坐标 B，垂直 y 是功能坐标 F。`1=(0,1)`、`3=(1,0)`、`7=(-1,0)`、`5=(0,0)`。值为 `Σ digit[k] × 3^k`，不是九进制，也不是无进位的 F9 运算。网页实现使用 BigInt 对两轴精确计算，并分别执行平衡三进制进位。

## 软件迭代

1. 功能增加：`V' = V + (0, 3^-p)`，沿 1 方向。
2. Bug 修复：`V' = V + (3^-p, 0)`，沿 3 方向。
3. 小数位：p=0、1、2、3 分别为 1、1/3、1/9、1/27。尺度由团队声明，不等同于任务数量、改动行数或 SemVer 的兼容性承诺。
4. 不稳定功能：从基线 V 沿 7 方向引入，`P = V + (-3^-p,0)`；预定成熟目标 `T = V + (0,3^-p)`。验证通过后撤销 7 偏移，再沿 1 方向计入稳定功能，即 `P + 3×3^-p + 1×3^-p = T`。这是功能成熟事件，不应当记为一次独立 bug 修复。
5. 9 方向：`V′ = V + (0,-3^-p)`，保留给高版本主动适配旧接口或旧行为。通常不使用；普通 bug 修复仍沿 3，不能因为修复服务于旧用户就归到 9。页面暂不提供常规 9 按钮。

不稳定功能复用了修复轴，并未创造第三个独立数学维度。因此必须单独保存 `channel=preview/stable`、`target` 和迭代精度。数字含 7 或坐标为负不等于实验版；正修复坐标也可能是实验版。仅看 DBT 数值不能判断稳定性。页面中的“转为稳定”只演示操作；真实发布仍需要项目自己的验证门禁。

## 编码与比较

- 文本使用 `&` 前缀，数字为 1–9，零写成 5。规范化时去掉多余的整数前导 5、小数末尾 5；原点写为 `&5`。
- 小数是三进制权重而非十进制：`&14.8` 精确表示 F=7/3、B=4/3。不能用 `parseFloat` 解码。
- F 和 B 都不少于另一版本时，才称数值坐标支配另一版本。功能更多但修复更少的两版本互不支配；字符串字典序、数字字符大小和复数范数都不用于迭代排序。
- 数值是二维地址，不是全局唯一发布身份。两条分支或不同渠道可以占据同一点。版本记录 ID 表示顺序；真实制品还应保存分支、提交 SHA、兼容性与渠道元数据。
- 当前页面的“实验”不累积多个未稳定偏移：先到达保存的目标，才能继续新的迭代。

## 初始化与交互

示例路径：`&5 → &1 → &19 → &14 → &14.1 → &14.8`。页面提供不同尺度的功能/修复/实验迭代、转稳定、轨迹节点选择、版本解码、复制、重置与 JSON 导出。新记录保存在当前页面内存；刷新后回到示例，导出可保留实验结果。

页面只支持本项目已声明的发布约定；“稳定”是记录渠道，不能替代向后兼容性声明。

## 与软件生产流程对齐

方向表达发布意图，坐标不是功能数、修复数或质量评分。每次发布应按主导意图选择方向；混合变更可以保留多个事件，发布记录关联同一制品。小数精度由团队按影响范围约定，不能凭改动行数机械决定。

预发布记录应关联明确基线、目标、提交 SHA 与测试结果。页面演示一个待成熟功能；实际项目可以维护独立的预发布分支，稳定分支继续修复，再经过合并与回归验证生成新的目标。转稳定按钮只模拟验证已经完成，不能代替 CI、灰度或回滚准备。

9 方向表达为旧版本提供兼容适配的意图，不表示丢弃现有功能或实际降低软件能力。兼容对象、范围、支持期限和破坏性变更仍须在发布说明中声明。进位产生的 7、9 字符只是编码；只有记录中的 action、channel 与变更说明具有生产语义。二维支配关系仅比较数值地址，不能据此断言稳定性、质量或升级安全。

## 正式草案与页面

详细条款见 [Balanced Version 0.1.0 草案](version-spec.md)。页面使用递归九宫格表达逐位地址，并单独放大小数区域；比较工具提供四结果偏序及 (F,B) 展示排序。真实发布先后按同一发布线的 sequence 判断。
